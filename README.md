## Функциональность

### Каталог и Товары

- **Просмотр списка**: Витрина товаров с изображениями и ценами.
- **Детальная карточка**: Полная информация о товаре, галерея изображений, технические характеристики.
- **Отзывы**: Блок отзывов покупателей (подгружаются динамически).

### 🛒 Корзина

- **Управление**: Добавление товаров, изменение количества, удаление позиций.
- **Персистентность**: Состояние корзины сохраняется в `localStorage`.
- **Расчеты**: Автоматический подсчет общей суммы и количества товаров.

### 👤 Личный кабинет

- **Профиль**: Отображение данных пользователя (аватар, имя, контакты).
- **Адрес и Оплата**: Визуализация адреса доставки и привязанных методов оплаты.
- **Настройки**: Возможность смены темы оформления.

### 💬 Чат

- **Общение в реальном времени**: Пользователи могут общаться с технической поддержкой в режиме реального времени.
- **WebSocket**: Реализовано с использованием WebSocket для мгновенного обмена сообщениями.

### 🎨 UI/UX

- **Темы**: Светлая и темная темы.
- **Адаптивность**: Интерфейс полностью адаптирован под мобильные устройства и десктопы.
- **Анимации**: Плавные переходы через `Transition` и `TransitionGroup`.

## 🔧 Технические особенности

Проект был значительно переработан для использования современного стека Vue 3:

- **Composition API**: Вся кодовая база переведена на Composition API с использованием синтаксиса `<script setup>`.
- **TypeScript**: Проект полностью переписан на TypeScript.
- **State Management**: Вместо Vuex используется **Pinia**. Модули хранилища (`stores`) типизированы и размещены внутри соответствующих функциональных модулей.
- **UI Framework**: Интегрирован **Vuetify 3**.
- **Архитектура**: Сохранена модульная структура, где функциональность сгруппирована по доменным областям (`modules`).
- **Слой API**: Реализован `Networker` — класс-обертка над `fetch` для централизованной обработки запросов, перехвата ошибок и автоматического обновления токенов и `WSChat` - класс-обертка над `WebSocket`.

## 🛠 Стек технологий

- **Framework**: Vue 3 (Composition API, `<script setup>`)
- **Typing**: TypeScript
- **State Management**: Pinia
- **UI Framework**: Vuetify 3
- **Routing**: Vue Router 4
- **WebSocket**: Интеграция для чата
- **Build Tool**: Vite
- **API**: [DummyJSON](https://dummyjson.com) (Auth, Products, Users), `wss://ws.ifelse.io` (WebSocket)
- **Linting**: ESLint, Prettier

## 📦 Установка и запуск

1. Клонируйте репозиторий и установите зависимости:
   ```bash
   npm install
   ```
2. Запустите локальный сервер разработки:
   ```bash
   npm run dev
   ```
3. Сборка для продакшена:
   ```bash
   npm run build
   ```

## 🔑 Тестовый вход

Для доступа к функциям личного кабинета используйте моковые учетные данные:

- **Логин**: `emilys`
- **Пароль**: `emilyspass`

> **Примечание**: Регистрация новых пользователей не работает, форма регистрации существует для полноты картины. DummyJSON не позволяет регистрировать пользователей.

## 📂 Структура проекта (src)

```text
src/
├── app/                  # Системный слой приложения
│   ├── assets/           # Глобальные стили, изображения, шрифты
│   ├── layout/           # Основные макеты страниц
│   └── config/           # Глобальные конфигурации
│       ├── router.ts     # Конфигурация маршрутизации
│       └── vuetify.ts    # Конфигурация Vuetify
├── modules/              # Модули, сгруппированные по доменам
│   ├── account/          # Личный кабинет
│   ├── auth/             # Авторизация и регистрация
│   ├── cart/             # Корзина (Store + UI)
│   ├── catalogue/        # Каталог товаров
│   ├── chat/             # Чат реального времени (WebSocket)
│   ├── home/             # Главная страница
│   ├── product/          # Страница товара
│   ├── reviews/          # Отзывы
│   ├── settings/         # Настройки (смена темы)
│   ├── shared/           # Общий код (API, типы, хелперы)
│   ├── user/             # Данные пользователя (Store + API)
│   └── vehicle/          # Данные о товарах (Store + API)
├── pages/                
└── widgets/              # Самостоятельные блоки интерфейса
```

## Lighthouse и валидация

### Как запустить тесты

Для запуска полного цикла валидации выполните команду:

```bash
npm run audit
```

### Отчет Lighthouse

Для генерации детального отчета Lighthouse выполните:

```bash
npx unlighthouse
```

Готовые отчёты расположены в корневой директории в виде `.html` файлов.
